# AUTHORITY OS

Sistema operacional de autoridade, conteúdo e crescimento local.

## Objetivo
Transformar perfis profissionais em máquinas de autoridade e oportunidade comercial. O foco não é apenas gerar posts: é conectar posicionamento, conteúdo, distribuição, conversas e oportunidades.

## MVP 1.0
- PWA instalável
- Authority Score
- Plano semanal de conteúdo
- Radar Local
- Growth Intelligence
- Funil de autoridade
- Calendário editorial
- Centro de comandos
- Interface responsiva para celular e desktop
- Modo offline básico

## Próxima fase
- Login e multi-tenant
- Neon/Supabase para dados reais
- Gemini para estratégia e criação de conteúdo
- n8n para automações
- Meta/Instagram API
- YouTube API
- TikTok API quando as permissões aplicáveis estiverem disponíveis
- WhatsApp/CRM para leads
- Métricas reais de alcance, visitas, DMs, leads e clientes
- Memória de marca por cliente
- Aprovação humana antes de publicações sensíveis

## Arquitetura sugerida
Frontend PWA -> API/Backend -> Banco -> Gemini -> n8n -> Canais sociais -> métricas -> Growth Intelligence
